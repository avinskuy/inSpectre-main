# Dataset wilayah Indonesia

File bmkg-regions.csv berasal dari:
https://github.com/cahyadsn/wilayah

Lisensi dataset: MIT. Salinan lisensi disimpan di BMKG-REGIONS-LICENSE.txt.

Kode wilayah harus divalidasi terhadap respons API BMKG sebelum digunakan.
Prakiraan dan peringatan cuaca bukan bagian dari dataset ini; keduanya diambil
dari sumber resmi BMKG.
